Mesure du canevas

Aucun service n'est appelé : les tuiles viennent de ce serveur local. Les mesures se font dans un worker, avec un OffscreenCanvas, comme sur la page de génération.

L'étape 3 encode des images de 80 et 164 millions de pixels : l'onglet peut se figer une minute, ou planter. Si c'est le cas, copiez d'abord le résultat des étapes 1 et 2.
